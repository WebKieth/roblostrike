# Музыка подготовки сессии

`shiza.mp3` — трек, предоставленный пользователем для экрана выбора команд и ботов.
Исходный MP3 не встраивается в place: Roblox проигрывает загруженные аудиоассеты.

1. В Creator Dashboard → Creations → Development Items → Audio загрузи `shiza.mp3`
   (при наличии прав на использование) и дождись модерации.
2. В разрешениях аудио добавь игру RoboStrike, Universe ID `10771463523`.
3. Скопируй Asset ID и задай в `src/shared/SessionRules.luau`:
   `SessionMusicSoundId = "rbxassetid://<Asset ID>"`.
4. Пересобери/синхронизируй проект и проверь звук в Studio и опубликованной игре.

Музыка зациклена, слышна только локальному игроку при начальной настройке
сессии и останавливается при старте. Меню M во время боя её не включает.
Громкость по умолчанию — 0,35 (`SessionMusicVolume`), учитывается общий
регулятор звука. Пустой ID отключает музыку до загрузки ассета.
